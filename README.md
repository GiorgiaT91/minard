# Leaves before the frost

An interactive redrawing of Charles Joseph Minard's 1869 chart of Napoleon's Russian campaign of 1812.

Each leaf is 10,000 men. The ring is the calendar, from 24 June to 14 December 1812. Leaves turn brown in autumn, frost over when Minard's temperature drops below zero, and fall as the army shrinks: most of them before the first frost.

**See it here: https://giorgiat91.github.io/minard/**

- Data: Minard (1869), via the [HistData](https://cran.r-project.org/package=HistData) R package. Dates between Minard's points are estimates added for this project.
- Built with [D3.js](https://d3js.org) and Martel Sans.
- Method inspired by Valentina D'Efilippo's masterclass *Visual Storytelling with Data*.

By Giorgia Tagliaferri.
